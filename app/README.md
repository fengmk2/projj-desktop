# Projj native interface

See the [repository README](../README.md) for setup, features, permissions, shortcuts, and limitations. Build the Rust helpers and generate the launch environment with `scripts/dev.sh` from the repository root. To run this directory directly after building, put `app/bin` on `PATH` and use `gpui-shell run -d app`.

Reference: [Projj](https://github.com/popomore/projj), [gpui-shell](https://gpui-kit.com/shell/), and the runtime examples in [gpui-shell-benchs](https://github.com/huacnlee/gpui-shell-benchs).
