# Walkthrough media

`projj-demo.mp4` is the 51-second desktop walkthrough shown in the main README. It includes an original instrumental soundtrack with soft electric keys, warm chords, bass, and light percussion at 80 BPM. The music fades in and out and uses no third-party recordings or samples. The demo assets use the repository's MIT license.
